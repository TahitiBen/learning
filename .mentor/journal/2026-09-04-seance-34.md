## Objectif
Rendre le gestionnaire robuste : messages clairs quand rien n'est trouvé/supprimé (fin du silence).

## Révision éclair
- `commit()` : **`conn.commit()`** (connexion + parenthèses) → **juste, ancré** ! 🎉
- Cold DELETE : `DELETE * FROM machines WHERE name = Test-Rev` → a remis un `*` (habitude SELECT) → recadré : **DELETE n'a pas de `*`** (`DELETE FROM machines WHERE nom = 'Test-Rev'`), `nom` pas `name`, guillemets. → syntaxe DELETE/UPDATE à froid : encore le réflexe `*` à corriger.

## Ce qui a été vu
- **Recherche vide** : stocker `resultats = cur.fetchall()`, puis `if not resultats: print("Aucune machine trouvee.")` sinon afficher.
- **`cur.rowcount`** : nombre de lignes affectées par la dernière requête → après UPDATE/DELETE, `== 0` = rien touché → message adapté.

## Ce qui a été fait — `inventaire_manager.py`
