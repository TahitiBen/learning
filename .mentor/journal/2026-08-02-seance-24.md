# Séance 24 — 2026-08-02 — SQL (4) : COUNT (agrégations)

## Objectif de la séance
Découvrir les agrégations avec `COUNT`.

## Révision éclair
- LIKE « commence par 192.168.5 » : a **oublié le `%`** (a écrit `LIKE '192.168.5'`) → recorrigé : **LIKE sans `%` = `=`**, il faut `'192.168.5.%'`. → LIKE/`%` encore fragile au rappel.
- Règle d'or WHERE (UPDATE/DELETE) : **« je sais plus »** → re-expliqué (sans WHERE = toute la table). → à re-driller.

## Ce qui a été vu
- `COUNT(*)` = nombre de lignes. `SELECT COUNT(*) FROM machines;`
- `COUNT(*)` + `WHERE` = compter les lignes filtrées (ex. par réseau).
- Mention des autres agrégats : `SUM`, `AVG`, `MIN`, `MAX` (sur colonnes numériques).

## Exercice fait
1. INSERT de 2 machines sur 192.168.1 (Serveur-DB, PC de Marc). ✓
2. `SELECT COUNT(*) FROM machines;` → **5** ✓
3. `SELECT COUNT(*) FROM machines WHERE ip LIKE '192.168.1.%';` → **3** ✓ (LIKE `%` bien mis cette fois)

## Difficultés / observations
- `COUNT` compris et appliqué sans souci.
- **Schéma confirmé** : LIKE `%` et règle du WHERE **oubliés au rappel oral**, mais **appliqués correctement en pratique** juste après correction (procédural > déclaratif). → garder LIKE `%` + règle WHERE en révision, via exemples concrets.

## Concepts — bilan
- `COUNT(*)` (+ WHERE) → **vu, réussi**. À recroiser.
- LIKE `%` / règle WHERE : fragiles au rappel, OK en pratique → révision continue.

## Prochaine étape prévue
**`GROUP BY`** : compter/agréger **par groupe** (ex. nombre de machines PAR réseau). Prérequis : ajouter une colonne `reseau` → occasion d'introduire **`ALTER TABLE ADD COLUMN`** puis de la remplir avec `UPDATE ... WHERE ip LIKE ...` (réutilise UPDATE+LIKE). Puis `SELECT reseau, COUNT(*) FROM machines GROUP BY reseau;`. Ensuite : jointures, puis SQL depuis Python (`sqlite3`). Drills : LIKE `%`, règle WHERE.
