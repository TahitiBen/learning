## Objectif (option C)
Installer et utiliser un module externe avec `pip` ; 1re requête HTTP avec `requests`.

## Révision éclair
- Cold JOIN : a **encore mis `WHERE` au lieu de `ON`** (pour la 2e fois) → mnémo martelé : **« une JOINture se fait ON une condition »**, `JOIN table ON …`. ⚠️ **`JOIN → ON` : point persistant, à driller à chaque séance.**
- LEFT JOIN vs JOIN : « j'ai oublié » ce que LEFT ajoute → re-expliqué (toutes les lignes de gauche, NULL sinon).

## Ce qui a été vu
- **`pip install <paquet>`** : installe une bibliothèque depuis **PyPI** (au-delà de la bibliothèque standard). `python -m pip install …` en secours.
- **`requests`** : bibliothèque de référence pour les requêtes HTTP. `requests.get(url)` → réponse ; `.json()` → parse le JSON.

## Exercice fait — `python\api_test.py`
`pip install requests`, puis `requests.get("https://api.ipify.org?format=json")` + `.json()` → a récupéré son **IP publique** (`{'ip': ...}`). Réussi.
