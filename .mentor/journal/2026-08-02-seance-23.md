# Séance 23 — 2026-08-02 — SQL (3) : ORDER BY, UPDATE, DELETE (CRUD complet)

## Objectif de la séance
Compléter le CRUD : trier (`ORDER BY`), modifier (`UPDATE`), supprimer (`DELETE`).

## Révision éclair
- Requête « IP commence par 10.0. » : a écrit `'10.0.%.%'` (trop restrictif) → `'10.0.%'` suffit.
- **`LIKE` : PAS compris au départ** (« j'ai toujours pas compris »). Ré-expliqué **concrètement** : analogie recherche téléphone (`Mar%` → Marie/Marc), tableau d'exemples sur ses données, + 2 requêtes à lancer lui-même → **a compris**. `%` = n'importe quelle suite de caractères. → LIKE à recroiser (abstrait pour lui, mais OK via exemples concrets).

## Ce qui a été vu
- **`ORDER BY nom`** (tri A→Z) / `ORDER BY nom DESC` (Z→A).
- **`UPDATE table SET col = valeur WHERE ...`**.
- **`DELETE FROM table WHERE ...`**.
- **⚠️ RÈGLE D'OR : toujours un `WHERE` avec UPDATE/DELETE** (sinon toute la table est touchée). Astuce : tester la condition avec un `SELECT ... WHERE ...` d'abord.

## Exercice fait — cycle complet sur une ligne jetable
1. `SELECT * FROM machines ORDER BY nom;` ✓
2. `INSERT ... VALUES ('Test','10.0.0.1');` ✓
3. `UPDATE machines SET ip = '10.0.0.99' WHERE nom = 'Test';` ✓ (WHERE !)
4. `DELETE FROM machines WHERE nom = 'Test';` ✓ (WHERE !)
5. `SELECT * FROM machines;` → 3 machines d'origine ✓

## Difficultés / observations
- **CRUD complet réussi**, WHERE bien mis sur UPDATE et DELETE (règle d'or appliquée).
- **Confirmation de son style d'apprentissage** : `LIKE` expliqué à l'oral ne passait pas ; avec des **exemples concrets + le fait de lancer les requêtes**, ça a immédiatement cliqué. → toujours privilégier « montre par l'exemple + fais-le » pour les notions abstraites.

## Concepts — bilan
- CRUD (CREATE/INSERT, SELECT, UPDATE, DELETE) + ORDER BY + règle du WHERE → **vu, réussi**. `LIKE` à reconfirmer.

**Agrégations** : `COUNT(*)` (compter des lignes), puis `GROUP BY` (regrouper — ex. compter les machines par réseau), et `MIN`/`MAX`/`AVG`/`SUM`. Ensuite : jointures (`JOIN`), puis relier SQL à Python (`sqlite3`). Drills : `LIKE`/`%` (via exemples), règle du `WHERE`.
