# Séance 30 — 2026-08-02 — sqlite3 : ÉCRIRE dans la base depuis Python

## Objectif
Écrire (INSERT) dans la base depuis Python (+ `commit`), et accéder aux colonnes d'une ligne.

## Révision éclair
- 5 étapes sqlite3 : n'avait que `import sqlite3` → redonné la chaîne **connecter → curseur → exécuter → récupérer → fermer**.
- Cold GROUP BY : `SELECT machines, COUNT(*) ... GROUP BY reseau` → mettait la **table** au lieu de la colonne → recadré : **la colonne du SELECT = la colonne du GROUP BY** (`reseau`). Progrès (l'astuce commence à mordre).

## Ce qui a été vu
- **Accéder aux colonnes** : chaque ligne = tuple `(id, nom, ip, reseau)` → `ligne[1]` = nom, `ligne[2]` = ip. `print(ligne[1], "->", ligne[2])`.
- **Écrire** : `curseur.execute("INSERT ...")` puis **`conn.commit()`** pour sauvegarder (sinon perdu — le « Ctrl+S » du code).
- **Distinction objets/méthodes** : `commit`/`close`/`connect` = **connexion** ; `execute`/`fetchall` = **curseur**.
