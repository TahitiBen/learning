# Séance 25 — 2026-08-02 — SQL (5) : GROUP BY (+ ALTER TABLE)

## Objectif de la séance
Agréger PAR groupe avec `GROUP BY` ; ajouter une colonne avec `ALTER TABLE`.

## Révision éclair
- Compter les machines du réseau 192.168.1 : `SELECT COUNT(*) ... WHERE ip LIKE '192.168.1.%'` → **juste** (LIKE `%` bien mis).
- `DELETE FROM machines;` sans WHERE → « supprime toutes les machines » → **juste**.
→ Les 2 points fragiles (LIKE `%` + règle WHERE) sont **maintenant restitués correctement** : la répétition espacée paie. Continuer à espacer.

## Ce qui a été vu
- **`ALTER TABLE machines ADD COLUMN reseau TEXT;`** : modifier la structure d'une table (ajouter une colonne, `NULL` pour les lignes existantes).
- Remplir la colonne avec `UPDATE ... SET reseau = '...' WHERE ip LIKE '...%'` (réutilise UPDATE + WHERE + LIKE).
- **`GROUP BY`** : regroupe les lignes par valeur de colonne, applique l'agrégat à chaque groupe → une ligne par groupe. `SELECT reseau, COUNT(*) FROM machines GROUP BY reseau;`.

## Exercice fait
- ALTER TABLE + 3 UPDATE (192.168.1 / .10 / .5) + GROUP BY. **Tout correct du 1er coup.**
- Résultat attendu : 192.168.1 → 3, 192.168.10 → 1, 192.168.5 → 1.

## Difficultés / observations
- **Séquence multi-étapes (ALTER + 3 UPDATE + GROUP BY) enchaînée sans faute** — belle autonomie sur du SQL, et réactivation solide du BTS.
- A réutilisé LIKE/UPDATE/WHERE correctement → consolidation des points fragiles par la pratique.

## Concepts — bilan
- `ALTER TABLE ADD COLUMN` + `GROUP BY` (+ agrégat par groupe) → **vu, réussi**. À recroiser.
- LIKE `%` + règle WHERE : restitués justes cette séance → en bonne voie (garder espacé).
