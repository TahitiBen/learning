## Le projet — `python\audit_reseau.py`
Demande un réseau, lit `hosts.txt`, filtre les machines de ce réseau, écrit `audit.txt` (en-tête daté + réseau, une ligne par machine, total). **Fonctionne au final.**

## Déroulé (évaluation — beaucoup d'itérations)
- v1 : n'utilisait PAS l'input (`print(input())` sans stockage), **3 réseaux codés en dur** en if/elif, `in entree` au lieu de `in ligne`, en-tête dans la boucle, index `[1]`/`[2]` (IndexError). → grosse reprise de structure guidée.
- v2 : input stocké, filtre unique `reseau + "." in ligne`, bons index + strip. Mais en-tête placé APRÈS la boucle.
- v3 : en-tête avant la boucle, mais **écriture de la machine sortie de la boucle** → écrivait toujours la dernière ligne (Imprimante) quel que soit le filtre ; `if compteur == 0` dans la boucle (prints répétés). A **repéré le bug lui-même** via ses tests (excellent réflexe de debug).
- v4 : écriture DANS la boucle/if, `if compteur == 0` après la boucle → **OK**.
