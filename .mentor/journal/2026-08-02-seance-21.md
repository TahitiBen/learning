## Ce qui a été vu
- Base SQLite = **un fichier** (`machines.db`).
- Vocab : base / table / colonnes / lignes.
- **`CREATE TABLE machines (id INTEGER PRIMARY KEY, nom TEXT, ip TEXT)`** — types `INTEGER`/`TEXT`, `PRIMARY KEY` (id unique, auto en SQLite).
- **`INSERT INTO machines (nom, ip) VALUES ('...', '...')`** — texte entre **guillemets simples**, `id` auto.
- **Enregistrer les modifications** (Ctrl+S) = persister dans le fichier ; onglet **Parcourir les données** pour voir.
