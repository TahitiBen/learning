## Ce qui a été vu
- **JOIN** : relier 2 tables au lieu de répéter une info. Ici `reseaux` (reseau, localisation) reliée à `machines`.
- Syntaxe : `SELECT t1.col, t2.col FROM t1 JOIN t2 ON t1.cle = t2.cle;` — le `ON` = condition de liaison ; préfixer les colonnes par leur table.

## Exercice fait
- `CREATE TABLE reseaux (reseau TEXT, localisation TEXT);` + 3 INSERT (Bureau / Etage 2 / Local technique).
- `SELECT machines.nom, machines.ip, reseaux.localisation FROM machines JOIN reseaux ON machines.reseau = reseaux.reseau;` → **5 machines avec leur localisation.** ✓

## Difficultés / observations
