## Objectif
Manipuler les chemins de fichiers proprement avec `pathlib` ; parcourir un dossier.

## Révision éclair
- **SQL à froid — DELETE** : `DELETE machines WHERE nom = 'Orpheline'` → oubli du **`FROM`**, corrigé (`DELETE FROM machines WHERE ...`). Règle d'or + pas de `*` respectés.
- **API JSON** : a d'abord écrit `reponse.json("followers")` (clé mise DANS `.json()`) → rappel que `.json()` ne prend pas d'argument, la clé va **entre crochets sur le dict** → corrigé (`donnees["followers"]`).

## Ce qui a été vu
- `pathlib` = module standard pour les chemins comme **objets** (pas de `pip`).
- `from pathlib import Path` ; assembler avec **`/`** (`Path("python") / "hosts.txt"`, bon séparateur selon l'OS).
- Méthodes : `.exists()`, `.name`, `.suffix`, `.parent` ; parcourir un dossier avec **`.iterdir()`**.
