## Révision éclair
- `commit()` sur quel objet + requête UPDATE : **les deux rouillés au rappel à froid** (a répondu ".execute INSERT" pour commit ; "UPDATE * FROM machines WHERE name…" pour l'UPDATE, confusion avec SELECT). Recorrigé : commit = **connexion** ; forme `UPDATE table SET col = val WHERE cond`. → cold production toujours à driller.

## Ce qui a été construit — `inventaire_manager.py`

→ **CRUD complet dans l'application.**
